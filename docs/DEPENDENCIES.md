# Dependencies

## Required

- FastAPI — HTTP API/UI host
- Uvicorn — ASGI server
- httpx — local Ollama and web HTTP
- psutil — system telemetry
- pydantic — request validation
- pypdf — PDF extraction
- python-dotenv — environment configuration

## Optional

- `openai-agents` — advanced cloud agent orchestration and optional fallback.
- `mcp` — MCP client integration.
- `playwright` — browser automation.
- `pyautogui` — computer input fallback.
- `SpeechRecognition`, `pyttsx3` — voice I/O.
- `sentence-transformers` — future semantic retrieval acceleration.

No model weights, credentials, `.env`, caches or private data are committed.
